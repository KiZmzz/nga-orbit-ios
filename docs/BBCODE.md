# NGA Orbit BBCode 兼容说明

本项目以 NGA 的两篇排版说明为真实样本：

- [《从入门到精通：排版的艺术 Ver.3》](https://ngabbs.com/read.php?tid=9268613)
- [《NGA 论坛代码大全（简易版）》](https://ngabbs.com/read.php?tid=23437206)

两帖共同强调了一个原则：排版服务于内容，手机端必须优先保证易读和兼容。Reader 因此解析 BBCode 数据并生成原生 SwiftUI 视图，不复制桌面网页的固定宽度排版。2026-09-07 已用两帖主楼的真实 BBCode 样本验证解析：详细帖约 25,866 字符 / 1,500 个原生节点，简易帖约 3,642 字符 / 336 个原生节点。

## 当前显示支持

| 类别 | 语法 | iOS 显示方式 |
| --- | --- | --- |
| 字体 | `[b]` `[i]` `[u]` `[s]` / `[del]` | 粗体、斜体、下划线、删除线 |
| 颜色与字号 | `[color=royalblue]` `[size=120%]` | 常用 NGA 颜色；字号限制在 14–24 pt |
| 对齐 | `[align=left/center/right]` `[l]` `[r]` | 对齐到手机内容栏；不做网页浮动环绕 |
| 段落 | `[quote]` `[collapse=标题]` `[h]` | 引用卡、折叠区、分隔线 |
| 列表 | `[list][*]项目[/list]` | 原生项目符号列表，可嵌套 |
| 表格 | `[table][tr][td]…` | 原生单元格；宽表横向滚动，忽略桌面列宽和合并提示 |
| 内容 | `[img]` `[url]` `[code]` | 图片查看器、HTTPS 链接、等宽代码块 |
| 站内链接 | `[tid=数字]` `[pid=数字]` | 打开对应 NGA 主题或回复链接 |
| 其他 | `[dice]` `[flash]` `[iframe]` | 骰子内容卡；音视频和嵌入内容显示为安全链接 |
| 表情 | `[s:组:名称]` `[:名称]` | 映射到 NGA 表情 CDN；未知名称保留原文字 |

## 嵌套规则

解析器按成对标签处理，支持引用、折叠、列表、字体效果之间的递归嵌套，最大深度为 12。代码块中的内容按原文显示，不继续解释其中的 BBCode。

老帖可能出现 `[quote][list]…[/quote][/list]` 这种交叉闭合，Reader 会先修复为正确顺序。引用头中的 `Reply to`、`[pid]Reply[/pid]` 和 `[uid]用户名[/uid]` 是网页导航元数据，会在进入引用卡前统一转换为简洁署名。连续文字、样式、链接和表情由同一个原生富文本段落排版，标签边界不会自行换行。

没有闭合或未知的标签保留为文字，避免解析器误删正文。单篇内容超过 250,000 字符时停止递归，防止恶意或异常内容阻塞界面。

## 发帖编辑器

回复编辑器的格式栏与显示解析器使用相同语法。选择一段文字后点格式按钮，会在选区外包裹对应标签；没有选区时会插入可直接替换的占位文字。当前提供粗体、颜色、引用、列表、链接、图片、折叠和代码，并可切换到“预览”检查最终原生排版。

图片仍需先得到可访问的 HTTPS 地址，再放入 `[img]地址[/img]`。NGA 网页中的附件上传协议依赖登录态和上传接口，目前编辑器不伪装成本地图片上传。

## 移动端取舍

- 桌面表格的 `td35`、`colspan`、`rowspan` 等宽度或合并参数不强制复刻；内容完整性优先。
- `[font=字体]` 保留内容，使用系统字体，避免缺字和不可用字体。
- `[flash]`、`[iframe]` 不嵌入执行远程页面，显示为可点开的 HTTPS 链接。
- 超大字号被限制，避免单个标题占满手机屏幕。
- 图片按内容宽度缩放；原图可点开查看。
