# NGA Orbit · 模块功能说明（产品功能规格）

> 本文件**只描述每个模块具备/规划的功能**，供功能对齐、测试与后续 UI 设计参考。
> **不含任何 UI 排版 / 视觉 / 布局规定**——页面怎么排、长什么样由 UI 设计方另行决定。

---

## 0. 概述

- **定位**：NGA 论坛阅读客户端。核心动线：**版块 → 主题 → 帖子**；含消息中心与本地收藏。
- **技术**：Swift 6 / SwiftUI；本地包 `NGAKit` 负责网络与解析（无第三方运行时依赖，无中转服务器）。
- **导航**：底部 4 个 tab——**首页 / 版块 / 消息 / 我的**。进入具体内容后**隐藏底部 tab**，保留顶部返回。

---

## 模块一：首页

- **用途**：用户自己的版块收藏 + 快速入口；会话状态的门面。
- **功能**：
  - [x] 连接状态卡（登录状态 / 状态文案 / 管理会话）
  - [x] 我的版块（本地保存；点击进入该版主题列表）
  - [x] 从版块目录收藏具体版面
  - [x] 账户入口
  - [ ] 最近访问
  - [ ] 推荐 / 常用版块
- **展示内容**：会话状态、收藏版面入口、空状态提示、脚注说明。

---

## 模块二：版块

- **用途**：论坛社区目录——按分类浏览 / 按名字搜索，找到并**进入**版块。
- **功能**：
  - [x] 两级分类导航 + 两列版面列表（版面图标 + 名字 + 可切换收藏星标）
  - [x] 版块真实图标
  - [x] 搜索（本地过滤 + 服务端搜索）
  - [x] 进入版块 → 主题列表：筛选（全部 / 置顶 / 精华 / 热帖）、置顶优先、相对时间、顶/精标
  - [x] 收藏版块
  - [x] 板内搜索主题
  - [x] 子版面入口（`sub_forums`）
  - [ ] 板块说明 / 简介
  - [ ] 主题列表缩略图
- **数据来源**：`bbs_index_data.js`（GB18030）、`thread.php`、`app_api?__lib=subject&__act=hot`、`forum_favor2`、`thread.php?key`、`sub_forums`。

---

## 模块三：消息

- **用途**：三类通知中心——**互动提醒 / 私信 / 系统消息**。
- **功能**：
  - [x] 三类切换
  - [x] 互动提醒列表（被回复 / @ / 点赞）
  - [x] 系统消息列表
  - [x] 私信列表（POST `nuke.php?__lib=message`；⚠ 需**账号登录**，游客会话会被拒）
  - [ ] 私信会话详情 / 发起私信
  - [ ] 点击提醒跳转对应主题 / 回复
  - [ ] 消息项 / 发送者头像
- **数据来源**：`nuke.php?__lib=noti`（提醒）、`nuke.php?__lib=message`（私信）。

---

## 模块四：我的

- **用途**：账户 / 会话管理。
- **功能**：
  - [x] 会话状态、NGA 站点切换
  - [x] 打开网页完成访问验证（WebKit）
  - [x] 登录 NGA 账号
  - [x] 清除本机 NGA 会话（退出登录）
  - [x] 关于此原型
  - [ ] 账号信息（等级 / 声望 / 徽章）
  - [ ] 设置（外观 / 阅读偏好 / 缓存）
- **数据来源**：WKWebView 会话 + 钥匙串；`nuke.php` 用户信息。

---

## 通用约束（功能层，非排版）

- **三态**：加载 / 空 / 错误都必须有，不展示假数据。
- **帖子内容**：BBCode，支持 `align` `size` `color` `list` `*` `b` `i` `u` `s` `quote` `img` `url` `code`，以及表情 `[s:组:名]`。
- **写操作**：回复、收藏主题、收藏楼、引用（走 `post.php` / `nuke.php`，需账号登录，待实测校准）。

## 数据来源汇总

| 用途 | 接口 |
| --- | --- |
| 版块目录 | `bbs_index_data.js`（GB18030） |
| 主题列表 | `thread.php` |
| 帖子 | `read.php` |
| 热帖 | `app_api?__lib=subject&__act=hot` |
| 板内搜索 | `thread.php?key` |
| 收藏版块 | `nuke.php?__lib=forum_favor2` |
| 收藏主题/楼 | `nuke.php?__lib=topic_favor_v2` |
| 提醒 | `nuke.php?__lib=noti` |
| 私信 | `nuke.php?__lib=message` |
| 回复 | `post.php` |
